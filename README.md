GLSurfaceView ImGui

Native Android ImGui Rendering Framework

A native-based GLSurfaceView + ImGui framework focused on smooth rendering, reliable input handling, performance, and broad Android compatibility.

✨ Features

- ⚡ Native NDK-based rendering
- 🎮 Multi-engine rendering support
- 📱 Android 7 → 16+
- 🧩 ARM & ARM64 support
- 👆 Smooth and reliable touch/input handling
- 🚀 Optimized for performance and stability
- 🔮 Future-ready architecture
- 🛠️ Flexible and integration-friendly
- 💨 Low-overhead ImGui rendering

🛠️ What I Do

Native Android Development • ImGui • Rendering • Optimization • Reverse Engineering Research • Custom Tooling

Focused on building efficient, stable, and highly compatible native Android systems.

🎯 Core

GLSurfaceView + OpenGL ES + Dear ImGui + Android NDK

«Native performance. Smooth rendering. Reliable input. Maximum compatibility.»
